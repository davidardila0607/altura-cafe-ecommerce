# altura-web

Frontend Angular 22 de **Altura**. La puesta en marcha completa (backend, productos de ejemplo y frontend) está en el [README principal](../README.md); los detalles técnicos, en [CLAUDE.md](../CLAUDE.md).

```powershell
npm install
npm start                       # http://localhost:4200 (requiere la API en http://localhost:5031)
npx ng build
npx ng test --watch=false       # Vitest
npx playwright install chromium # una vez
npm run e2e                     # Playwright
```
